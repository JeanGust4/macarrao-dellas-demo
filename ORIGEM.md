# Origem da demonstração

Repositório de referência: https://github.com/rafaelenpires/macarrao-dellas

Revisão analisada: `187ec8fcdff109c299fc02647397e1d6045cf86d`

Esta é uma versão independente reimplementada para Next.js/Vercel. Catálogo, identidade e imagens foram reaproveitados como referência. Não é uma cópia bit a bit e não foi enviada ao repositório original. O histórico Git original não acompanha o pacote. As ilustrações SVG das bebidas foram criadas localmente para esta demonstração.

A versão atual também inclui a integração da assistente Rafaele com a API do Google Gemini, implementada nesta demonstração para oferecer respostas conversacionais e recomendações contextualizadas pelo cardápio.
